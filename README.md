# Tap Tile v2.0

بازی حافظه فارسی آفلاین برای اندروید، با رابط کاربری بازطراحی‌شده و مناسب انتشار در مارکت.

## تغییرات این نسخه

- جایگاه تبلیغاتی MediaAd در پایین تمام صفحات، با loader واقعی و شناسه جایگاه `mediaad-JRm7j`
- حذف وابستگی به SDK حدسی تبلیغات کافه‌بازار؛ تبلیغات فعلی از MediaAd لود می‌شوند
- ۱۴ موضوع بازی: پرچم‌ها، حیوانات، طبیعت، فضا، خوراکی‌ها، ورزش، اشیاء، اشکال، رنگ‌ها، میوه‌ها، وسایل نقلیه، فناوری، موسیقی، سفر و ایموجی
- ۳۰ مرحله با افزایش تدریجی تعداد جفت‌ها
- XP محلی برای ایجاد حس پیشرفت
- چیدمان بهتر مراحل و موضوع‌ها
- تنظیمات صدا و ویبره
- رکورد محلی
- آیکون جدید
- چهار اسکرین‌شات تبلیغاتی 1080×1920 در پوشه `store-assets`
- حذف MainActivity تکراری و یکدست‌سازی namespace / applicationId
- بهبود WebView و چرخه عمر Activity
- بدون وابستگی جاوااسکریپتی خارجی و بدون نیاز به اینترنت برای خود بازی

## تبلیغات MediaAd

جایگاه تبلیغات پایین تمام صفحات با شناسه `mediaad-JRm7j` در HTML قرار گرفته و loader رسمی زیر در صفحه بارگذاری می‌شود:

`https://s1.mediaad.org/serve/keynu.ir/loader.js`

برای نمایش تبلیغ واقعی، دستگاه باید هنگام اجرای بخش تبلیغات به اینترنت دسترسی داشته باشد. خود منطق بازی، مراحل، رکوردها، XP و فایل‌های بازی به‌صورت محلی داخل APK قرار دارند.

پروژه را در Android Studio باز کنید و Gradle Sync و سپس Build APK را اجرا کنید.
